# Ghost in the Memory

One of our developers insists that his computer has been compromised. He downloaded and executed a file, after which a black screen appeared. However, no suspicious files were found on the system. Fortunately, we were able to capture a memory dump while the machine was still running. Your task is to analyze the memory dump and uncover what is being hidden.
